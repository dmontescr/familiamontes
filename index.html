Sincronización con GitHub

Para que el botón «Guardar en la nube» realice commits automáticos en el repositorio al editar desde la web desplegada en Cloudflare Pages, debes configurar las siguientes variables de entorno en el panel de Cloudflare:

  • GITHUB_TOKEN: Personal Access Token (classic o fine-grained con permiso Contents: Read and write).
  • GITHUB_OWNER: Tu usuario u organización de GitHub (ej. dmontes).
  • GITHUB_REPO: Nombre del repositorio (ej. Web-Familia-Montes).
  • GITHUB_BRANCH: (Opcional) Rama objetivo, por defecto main.

📌 En local o sin Cloudflare Pages, los cambios se guardan siempre en la memoria local (localStorage) y puedes exportar e importar archivos .json en cualquier momento.
